## Все вы слышали про нейрослоп... представляю вам нейросвоп

**Warning**: lstm с 24 параметрами местами не идеально запоминает вашу память

### Usage

**Warning(для особо одаренных)**: пробовать только на виртуалке, речь идет не о возможных ошибках в коде, а о намеренной записи мусора в память

Сборка (запускать make надо именно из kmodule, make -C kmodule не робит)

    cd kmodule && make

Подключить модуль

    cd kmodule && sudo insmod nswap.ko

Делаем swap

    sudo mkswap /dev/nswap
    sudo swapon /dev/nswap

Прогнать тесты

    make test

Если подключен модуль так-же прогонятся тесты девайса. Результат будет отличатся,
т.к. нет ресета состояния lstm между тестами

Обучить модель:

    make train

веса модели запишутся хардкодом в kmodule/weights.h

### Common issues
